# testDesigner

Vue3 + TypeScript dynamic form designer based on PageForm schema.

Features:
- drag component to canvas
- generate TempEditForm schema
- field property editing
- rules/options generation
- JSON schema export

Structure:

```
testDesigner/
├── FormDesigner.vue
├── DesignerMaterial.vue
├── DesignerCanvas.vue
├── DesignerSetting.vue
├── DesignerJsonEditor.vue
├── sortable.ts
└── index.ts
```
